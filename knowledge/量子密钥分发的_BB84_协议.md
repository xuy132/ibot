# 量子密钥分发的 BB84 协议

## 核心要点

| 维度 | 关键概念 | 说明 |
|------|----------|------|
| **目标** | 通过量子态实现两方（Alice 与 Bob）安全共享随机密钥 | 任何窃听都会导致可测量的误码 |
| **量子比特编码** | 两个正交基（Z 轴：|0⟩,|1⟩）与两个相位基（X 轴：|+⟩,|−⟩） | Alice 随机选择基与比特值 |
| **发送与测量** | Alice 发送 N 组随机编码的量子比特；Bob 随机选择测量基 | 仅在基相同的情况下测量结果可信 |
| **公开基信息** | Bob 公开其测量基，Alice 公开其编码基 | 仅保留基相同的比特作为“保留比特” |
| **错误率估计** | 随机抽取部分保留比特进行比较 | 若误码率低于阈值（≈ 11%），则认为安全 |
| **隐私放大** | 通过信息重叠（如两步压缩）消除窃听者可能获得的信息 | 最终得到较短但安全的共享密钥 |
| **安全性依据** | 量子不可克隆定理与测不准原理 | 窃听会不可避免地引入错误，能被检测 |

## 建议下一步

1. **阅读原始论文**：Charles H. Bennett & Gilles Brassard, *Quantum Cryptography: Public Key Distribution and Coin Tossing* (1984)。  
2. **实验模拟**：使用 Qiskit 或 Cirq 实现 20‑bit BB84 并测量误码率。  
3. **深入安全分析**：研究 Shor–Preskill 证明与信息理论安全界限。  
4. **扩展协议**：了解 E91、SARG04、以及基于连续变量的 QKD。  
5. **硬件落地**：关注激光器、单光子探测器与光纤传输的技术进展。  
6. **法律与标准**：查看 ISO/IEC 18033‑3、IEEE 1686‑2021 等 QKD 标准与合规性。
