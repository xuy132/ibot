# 《道德经》学习笔记

## 基本信息
- **作者**：老子（约公元前6世纪）
- **成书时间**：先秦时期，后传为《道德经》
- **体裁**：哲学论述，81 节短句
- **篇幅**：81 节，约 1,200 字
- **影响**：道家思想奠基，影响哲学、政治、文学、艺术等领域

## 主要人物 / 概念
| 关键词 | 简述 |
|--------|------|
| **道** | 最高原理，万物之源，形而上、不可言说 |
| **德** | 道的具体化，体现为人的行为与品德 |
| **无为** | 不干预自然规律，顺其自然，强调“无所为” |
| **太极** | 阴阳互补的统一体，宇宙根本原理 |
| **阴阳** | 对立统一的基本二元，互相制约、转化 |
| **柔弱** | 以柔克刚，强调柔性力量 |
| **知足** | 适度满足，避免贪欲 |

## 核心思想
1. **道法自然**：万物由道生，遵循自然规律，主张“无为而治”。  
2. **柔弱胜刚强**：柔软、顺从的力量能克服刚硬，强调“以柔制刚”。  
3. **知足常乐**：强调内在满足，减少欲望，达到心灵宁静。  
4. **无为而治**：政治治理应顺应自然，减少干预，提倡“以无为之治”。  
5. **阴阳平衡**：一切事物都是阴阳相互作用的结果，强调和谐统一。  

## 学习要点
- **节选阅读**：挑选“道可道，非常道”“天下皆知美之为美，斯恶已”等关键句，逐句解读。  
- **对照现实**：将“无为而治”与现代治理、管理理念对照，探讨其适用性。  
- **阴阳思维**：练习将日常问题拆解为阴阳两面，寻找平衡点。  
- **柔性行动**：在冲突中尝试柔性沟通，观察“以柔克刚”的效果。  
- **自我修养**：每日反思是否“知足”，减少欲望，培养内在宁静。
