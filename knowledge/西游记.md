# 《西游记》学习笔记

## 基本信息
- **作者**：吴承恩（明代）
- **完成时间**：约 1580–1590 年
- **体裁**：神魔小说、长篇寓言
- **篇幅**：一百回（全书共 100 章）
- **出版**：民国初期正式出版，现已成为中国四大名著之一。

## 主要人物 / 概念
| 角色 | 简述 |
|------|------|
| **孙悟空** | 机智勇敢、七十二变，代表“反叛与自由”。 |
| **猪八戒** | 好色懒惰、可爱滑稽，象征人性弱点。 |
| **沙僧** | 忠诚稳重、踏实勤劳，代表“执着与担当”。 |
| **唐僧（唐三藏）** | 仁慈慈悲、坚定信念，象征“信仰与修行”。 |
| **白骨精、牛魔王、铁扇公主** 等妖怪 | 代表外在诱惑与内在考验。 |
| **“取经”** | 取佛经、修行成道的象征。 |
| **“九九八十一难”** | 旅途中的九九八十一关，象征修行过程中的磨难与成长。 |

## 核心思想
- **修行与自我提升**：通过师徒四人取经之路，阐释“修身、齐家、治国、平天下”的道德观。  
- **人性与善恶**：妖怪与人类角色交织，揭示善恶并非绝对，需通过智慧与努力辨别。  
- **团队合作**：四人各有长短，互补协作，强调集体力量的价值。  
- **幽默与讽刺**：以夸张、幽默手法批判社会弊端，具有深刻的社会寓言意义。

## 学习要点
1. **人物性格对比**：悟空的机智、猪八戒的贪婪、沙僧的忠诚、唐僧的慈悲，分别对应不同的修行路径。  
2. **“九九八十一难”**：每一关都象征一种内在修为或外在考验，记忆并理解其寓意。  
3. **神话符号**：如金箍棒、如来佛、七十二变等，都是道家与佛家思想的象征。  
4. **文本结构**：前半段以妖怪闹剧为主，后半段则逐渐升华为精神修行。  
5. **现代启示**：团队协作、勇敢面对挑战、不断自我反省与成长，适用于个人发展与团队管理。
